# Record architecture decisions

We record decisions that are hard to reverse or surprising without context as short ADRs in `docs/adr/`, numbered in order, one decision each. Domain vocabulary lives in `GLOSSARY.md`; ADRs use those terms.

## Consequences

- A decision that changes an earlier one supersedes it by a new ADR rather than editing the old one.
- Routine implementation choices do not get an ADR.
